# AI Pages page releases

The maintainer has given standing approval for all future pull request merges into `main` in `Ratslayer/language` and every repository that supplies a page to AI Pages, including future page repositories. The audience is prototype testers. After completing and testing a requested page change, merge its PR into `main` and publish the signed page update through the catalogue workflow without asking for per-release confirmation.

The page repositories are listed in [catalog-sources.json](catalog-sources.json). When adding a page repository, record this standing approval in its root `AGENTS.md` so it is available when working in that repository directly.
